# Gym Progress Tracker — Installable App

This package is a Progressive Web App (PWA).

Important: Android Chrome cannot install a PWA directly from a `file://` HTML file.
The files need to be opened from HTTPS (or localhost).

Once hosted, open the site in Chrome on your phone and choose:
Menu (⋮) → Add to Home screen / Install app.

After the first load, the app is designed to work offline and keep its local data.
